Tela gráfica 64 bits (experimental)
Ligar tela gráfica (VGA)Desenha a tela por captura (~1 quadro/s) e envia teclado/mouse pelo monitor do QEMU. Substitui o console serial. Com um build SDL2 próprio, coloque -display sdl em "Argumentos extras".

Você precisa fornecer sua própria ISO. Mouse: clique na tela para capturar (Esc solta).

Linux próprio (experimental)

Só console serial (esta build não tem tela gráfica). O arquivo vai para a memória da aba, então use imagens pequenas.

Sistema padrão: Alpine Linux x86_64 (vim, python3). Usuário root, sem senha.

Pronto. Clique em Ligar VM. O primeiro carregamento baixa uns 150 MB (depois fica em cache).
